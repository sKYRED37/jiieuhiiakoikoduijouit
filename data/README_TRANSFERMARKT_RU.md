# Данные Transfermarkt для Football Manager Bot

Папка содержит скрипт загрузки открытого набора данных игроков из проекта `dcaribou/transfermarkt-datasets`.

## Загрузка в Bothost

1. Убедитесь, что хостинг разрешает исходящие HTTPS-соединения.
2. В корне проекта выполните `python data/download_transfermarkt.py`.
3. Скрипт сохранит `transfermarkt_players.csv` рядом с `main.py`.
4. Перезапустите бота. При старте `main.py` импортирует игроков, чьи названия клубов совпадают с клубами в игре.

Если у хостинга нет доступа к интернету, запустите скрипт локально и загрузите полученный `transfermarkt_players.csv` в корень проекта Bothost.

## Важно

- Данные сообщества не являются официальным API Transfermarkt и могут отставать от текущих составов. На момент подготовки источником заявлен срез по 6 июля 2026 года; составы сезона 2026/27 могут отсутствовать.
- Transfermarkt не публикует игровой OVR. Если рейтинг не указан в CSV, бот оценивает его приблизительно по рыночной стоимости и возрасту.
- Импорт сопоставляет игроков с клубами, уже заведёнными в игре; клубы с несовпадающими названиями перечисляются в журнале запуска.
- Источник: https://github.com/dcaribou/transfermarkt-datasets
