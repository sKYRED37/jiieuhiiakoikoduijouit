# Football Manager Bot — полный проект для Bothost

## Установка
1. Загрузите содержимое ZIP в проект Bothost (файлы должны лежать в корне проекта, `main.py` не должен быть внутри вложенной папки).
2. В переменных окружения Bothost задайте `BOT_TOKEN` со своим Telegram Bot Token. Не публикуйте токен в чат или Git.
3. Установите зависимости из `requirements.txt` (обычно панель делает это автоматически).
4. Точка запуска: `python main.py`. Для платформ, поддерживающих Procfile, включён `Procfile`.
5. Убедитесь, что SQLite-файл `fm_multileague.sqlite3` хранится на постоянном диске/volume Bothost, иначе данные могут пропасть после пересоздания контейнера.
6. Добавьте бота в группу. Для административных команд бот должен уметь проверять статус пользователя в группе.

## Команды
- `/start`, `/help`, `/commands` — список команд.
- `/leagues` — выбрать один из 7 чемпионатов и свободный клуб.
- `/myteam` — профиль клуба и визуализация стартового состава.
- `/squad` — полный состав своего клуба; `/squad Arsenal` — найти состав клуба по названию.
- `/roles` — изменить игровую позицию игрока.
- `/mlsetup` — администраторская подготовка лиг, календаря и составов.
- `/mlround` — выбрать одну лигу или сыграть тур во всех лигах (администратор).
- `/mltable`, `/mlcalendar`, `/calendar` — таблицы и календарь.
- `/playerprofile имя_или_ID`, `/playerstats` — профили и статистика игроков.
- `/goldenball 2026/27` — выдать «Золотой мяч» (администратор).
- `/teamprofile` — трофеи и история призовых команды.
- `/market`, `/transfer`, `/contracts`, `/training`, `/coaches` — менеджмент клуба.
- `/cups`, `/finishcup ЛЧ 2026/27` — кубковые турниры и вручение трофея.
- `/finishseason ID_лиги 2026/27` — завершить одну лигу после всех матчей.
- `/finishallleagues 2026/27` — завершить все семь лиг после всех матчей.

## Составы игроков
Если реальный CSV рейтингов не импортирован, бот один раз создаёт для каждого клуба полный вымышленный состав из 23 игроков с латинскими англоязычными именами. Составы сохраняются в SQLite и не пересоздаются при перезапуске. Это не официальный список настоящих игроков. Можно заменить сгенерированные составы CSV-данными через функцию `career_multileague.import_fc27_csv(...)` после проверки структуры CSV и соответствия названий лиг/клубов.

## Примечания
- Матчи и статистика симулируются внутри игры; реальные футбольные данные не используются автоматически.
- Перед первым запуском создаётся SQLite база. Перед обновлениями делайте её резервную копию.
- Не удаляйте `fm_multileague.sqlite3` после начала игры.

## Реальные составы из Transfermarkt

Проект поддерживает импорт CSV-датасета Transfermarkt. Положите файл с именем
`transfermarkt_players.csv` в ту же папку, где находится `main.py`. Поддерживаются
поля распространённого открытого набора `players.csv`: `name`, `current_club_name`,
`date_of_birth`, `position`, `market_value_in_eur`, `current_club_domestic_competition_id`.
Также поддерживаются обычные `age`, `overall`/`ovr`, `potential`, `wage`.

На старте бот импортирует игроков из CSV. Если файл присутствует, генератор вымышленных
составов отключается, чтобы не смешивать настоящих футболистов с вымышленными. Поэтому
клубы, которых нет в CSV или которые не сопоставились по имени, останутся без состава;
смотрите лог запуска и число `unmatched clubs`. Сопоставление названий может требовать
дополнения под конкретный CSV.

Transfermarkt не задаёт официальный игровой OVR. Если в CSV нет столбца `overall`/`ovr`,
проект рассчитывает приблизительный игровой рейтинг по рыночной стоимости и возрасту и
помечает его как оценочный. Рыночная стоимость и оценочный OVR — разные показатели.

Важно: в архиве нет готового полного дампа всех игроков Transfermarkt. Получите CSV из
источника данных, на использование которого у вас есть право, и добавьте его в Bothost.
Сайт Transfermarkt: https://www.transfermarkt.com/ . Публичный исследовательский набор
Transfermarkt datasets: https://github.com/dcaribou/transfermarkt-datasets (проверьте актуальность,
лицензию и условия использования исходных данных перед развёртыванием).
