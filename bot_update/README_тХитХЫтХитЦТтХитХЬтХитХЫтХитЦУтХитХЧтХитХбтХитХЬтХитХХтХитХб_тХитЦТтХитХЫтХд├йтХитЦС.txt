ВИРТУАЛЬНЫЙ FOOTBALL MANAGER BOT — ОБНОВЛЕНИЕ V3

В архиве сохранены исходные файлы v2 и добавлен career_multileague.py.

Что умеет новый backend:
- 7 отдельных лиг, отдельные таблицы, календарь и круговой календарь матчей;
- выбор клуба многими участниками: один Telegram user = один клуб, один клуб = один менеджер;
- атомарная проверка занятости клуба, чтобы два пользователя не забрали одну команду одновременно;
- симуляция тура для каждой лиги и расчёт таблицы;
- общий сезонный календарь с международными паузами и трансферными окнами;
- импорт игроков/рейтингов из CSV с FC 27 ratings database. Код НЕ выдумывает имена и рейтинги.

ВАЖНО ПРО РЕАЛЬНЫЕ СОСТАВЫ FC 27
Официальная база рейтингов EA доступна здесь:
https://www.ea.com/games/ea-sports-fc/ratings
В базе 19 000+ игроков. В архиве нет выдуманной «полной базы FC 27»: CSV необходимо выгрузить/подготовить из источника рейтингов, затем импортировать функцией import_fc27_csv(...). Импорт требует точного совпадения названий лиг и клубов; для названий EA, отличающихся от каталога, нормализуйте их в CSV.
Данные о составах и рейтингах — только из импортированного CSV, никаких фальшивых FC 27 рейтингов.

БЫСТРЫЙ СТАРТ НОВОГО BACKEND
1. Положите career_multileague.py рядом с ботом.
2. В Python запустите один раз:
   import career_multileague as ml
   ml.install()
   ml.seed_calendar()
3. Сгенерируйте календарь каждой лиги:
   for league in ml.league_list():
       ml.generate_fixtures(league['id'], season=league['season'])
4. Импорт составов:
   ml.import_fc27_csv('fc27_ratings.csv')
6. Подключите UI-маршрутизатор в главном файле бота: `from career_multileague_ui import router as ml_router`, затем `dp.include_router(ml_router)` (проверьте порядок с существующим router).
5. Примеры:
   ml.clubs(free_only=True)             # свободные клубы
   ml.claim_club(telegram_id, name, club_id) # закрепить клуб
   ml.my_club(telegram_id)              # клуб менеджера
   ml.table(league_id)                  # таблица конкретной лиги
   ml.play_round(league_id, 1)           # симулировать тур
   ml.calendar()                        # календарь сезона

АРХИТЕКТУРА И СОВМЕСТИМОСТЬ
- career_multileague.py использует отдельный SQLite-файл fm_multileague.sqlite3, чтобы не сбросить существующую карьеру из career.py.
- Это рабочий backend-модуль, но его функции ещё нужно подключить к конкретным aiogram-обработчикам в основном файле бота. В имеющемся пакете нет db.py, engine.py и главного bot.py, поэтому безопасно подменить существующий движок/роутер невозможно.
- Список клубов — каталог, сохранённый из прежней версии (в основном сезон 2025/26), и перед открытием карьеры сезона 2026/27 его надо сверить с актуальными составами лиг.
- В имеющемся UI уже есть кнопки «Календарь» и «Таблица», но старые обработчики относятся к исходной одной лиге. Для 7 отдельных таблиц используйте ml.table(league_id) и подключите выбор лиги в aiogram.
- Нужны Python 3.10+; текущий Telegram UI использует aiogram 3.x.

Официальная страница EA Sports FC 27 Ratings:
https://www.ea.com/games/ea-sports-fc/ratings

КОМАНДЫ НОВОГО UI (после подключения router):
- /mlsetup — создать календарь и расписание всех семи лиг (выполнять один раз для нового сезона);
- /leagues — выбрать свободный клуб; занятые клубы скрыты;
- /myteam — показать клуб и импортированный состав;
- /mltable — таблица выбранной лиги;
- /mlcalendar — общий календарь сезона;
- /mlround — администратор группы запускает очередной тур во всех лигах.

НОВЫЕ ФУНКЦИИ ТРЕНЕРОВ И СОСТАВА
- /coaches — каталог тренеров, цены от €500 тыс. до €25 млн, максимум 5 разных тренеров на клуб; цена вычитается из бюджета.
- /training — выбрать игрока и шаблон тренировки (техника, физика, тактика, удары, оборона, вратари, комплексная, развитие молодёжи).
- Чем выше суммарный уровень нанятых тренеров, тем быстрее копится прогресс. OVR ограничен 99 и индивидуальным potential игрока.
- /myteam — при наличии Pillow (pip install pillow) отправляет динамическую схему состава на поле с номерами, именами, игровыми позициями и отдельным списком запасных; рейтинги отдельных игроков на схеме не показываются. Если Pillow нет, отправляет текстовый состав.
- Игроки и рейтинги берутся из импортированного FC 27 CSV; шаблон FC27_ИМПОРТ_ШАБЛОН.csv не является реальным составом — замените строку-пример своими данными.

Для подключения UI в главном файле: `from career_multileague_ui import router as ml_router`; `dp.include_router(ml_router)`.

ОБНОВЛЕНИЕ: РОЛИ ИГРОКОВ
- Добавлена команда /roles для директора клуба (пользователя, который закрепил клуб за собой).
- Директор выбирает игрока и назначает ему игровую роль: ВР, ЦЗ, ЛЗ, ПЗ, ЦОП, ЦП, ЦАП, ЛП, ПП, ЛФ, ЦФ или ПФ.
- Изменения записываются в SQLite и отображаются в составе; чужим клубом управлять нельзя.
- Для подключения используйте dp.include_router(career_multileague_ui.router).

Примечание: текущая версия показывает графику состава через /myteam. Для полноценной заставки именно перед очным матчем двух пользователей потребуется подключить её к существующему механизму регистрации/начала матчей основного бота; в этом архиве отдельный механизм регистрации матча не обнаружен.


Визуальный стиль профиля команды: тёмная панель, зелёное поле, футболки-маркеры без лиц, номера и роли. Команда /myteam генерирует схему из реального состава клуба; файл «пример_дизайна_состава.png» приложен только как визуальный референс.
