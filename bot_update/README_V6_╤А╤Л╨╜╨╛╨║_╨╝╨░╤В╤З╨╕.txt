FOOTBALL MANAGER BOT — V6: трансферы, контракты, форма, усталость и турниры

Файлы:
- career_economy.py — backend для трансферного рынка, зарплат/контрактов, усталости и еврокубков.
- career_economy_ui.py — aiogram 3 команды и кнопки.
- career_multileague.py — интервал между турами в расписании изменён на 3 дня.

Установка:
1. Сделайте резервную копию базы данных и проекта.
2. Скопируйте новые/обновлённые .py файлы в каталог бота.
3. В основном файле после создания dp зарегистрируйте оба роутера:
   import career_multileague_ui
   import career_economy_ui
   dp.include_router(career_multileague_ui.router)
   dp.include_router(career_economy_ui.router)
4. Один раз вызовите career_economy.install() при старте приложения (после настройки импортов).
5. Выполните /mlsetup для подготовки расписания. Новое расписание использует 3-дневный шаг; уже созданные матчи нужно пересоздать только если хотите применить новые даты.

Команды:
/mlround — администратор группы выбирает все лиги или одну лигу.
/market — обновление трансферного рынка и входящие предложения клубу пользователя; принять/отклонить кнопками.
/contracts — зарплаты, сроки контрактов, усталость и форма игроков.
/cups — отдельные турниры ЛЧ, ЛЕ и ЛК с собственными раундами.

Логика:
- Трансферная стоимость оценивается по OVR, возрасту и market_value; ИИ предлагает сумму около рыночной цены.
- Продажа клуба с менеджером требует подтверждения кнопкой; решение может принять только владелец клуба.
- Зарплата хранится как недельная сумма в евро; контракт 1–5 лет.
- После симуляции матча усталость растёт, форма слегка меняется; затем применяется восстановление, эквивалентное 3 дням отдыха.
- ЛЧ/ЛЕ/ЛК хранятся в отдельной таблице и симулируются отдельно от национальных лиг.

Ограничения и проверка перед продакшеном:
- Это расширение для предоставленных модулей, а не готовый автономный бот. Обязательно интегрируйте роутеры в существующий entrypoint и протестируйте на копии базы.
- Генерация европейских турниров сейчас использует 16 случайных клубов из базы и упрощённую сетку на выбывание; это игровая модель, не точный регламент UEFA.
- ИИ-рынок обновляется при вызове /market; для постоянной симуляции нужен периодический вызов ai_market_tick() в существующем игровом цикле.
- Результаты симуляции и экономика балансируются приблизительно; до запуска с реальными пользователями нужно протестировать несколько сезонов.
