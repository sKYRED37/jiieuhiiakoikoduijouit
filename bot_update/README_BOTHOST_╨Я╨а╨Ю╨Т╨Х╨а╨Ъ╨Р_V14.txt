Football Manager Bot — исправления V14 (дополнение к исходному проекту)

Исправлено:
- При успешном завершении сезона в одной лиге возраст каждого игрока этой лиги увеличивается ровно на 1 год.
- В той же операции меняется общий рейтинг по возрастной модели: до 21 года возможен небольшой рост до потенциала; 22–28 лет рейтинг стабилен; после 28 лет постепенно появляется спад, сильнее после 32 лет.
- Повторное завершение сезона блокируется таблицей season_closures, поэтому возраст не должен повторно прибавляться за тот же сезон.
- Python-модули из этого архива прошли проверку синтаксиса (py_compile).

ВАЖНО: этот архив НЕ является полным самостоятельным ботом. В исходном V13-архиве отсутствуют точка входа (main.py/bot.py), а также базовые модули db.py и engine.py, на которые ссылается старый проект. Без исходного полного проекта запуск на Bothost невозможен. Это дополнение нужно добавить в корень исходного репозитория, заменив одноимённые файлы.

Интеграция в main.py существующего проекта (aiogram 3):
    import career_multileague as ml
    import career_economy as eco
    from career_multileague_ui import router as multileague_router
    from career_economy_ui import router as economy_router

    ml.install()
    eco.install()
    dp.include_router(multileague_router)
    dp.include_router(economy_router)

Не добавляйте токен в код. В Bothost задайте переменную окружения BOT_TOKEN так, как ожидает точка входа вашего проекта.
Зависимости из requirements-bothost.txt нужно объединить с requirements.txt основного проекта.

О возрасте:
- career.py в старой системе уже увеличивал возраст на 1 при ежегодном развитии через _develop_players(). Не запускайте две системы карьеры параллельно на одной базе.
- Новый возрастной алгоритм относится к отдельной базе career_multileague.py и выполняется при /finishseason или /finishallleagues.

Имена игроков:
- Импортированные имена берутся из CSV состава. Этот архив не содержит полного актуального CSV с реальными игроками, а предыдущий CSV был лишь строкой-примером. Замените его настоящим CSV состава с латинским написанием имён; не импортируйте строку-пример.
- Автоматически переводить настоящие имена игроков в «английские ники» небезопасно: можно испортить идентичность игроков. Для вымышленных игроков генератор находится в engine.py, которого не было в V13-архиве, поэтому корректно исправить генерацию имён без исходного файла нельзя.

Проверки, которые нужны после получения полного проекта:
- запустить импорт модулей в среде Bothost;
- проверить миграции SQLite и сохранение базы в постоянном каталоге;
- сыграть полный сезон тестовой лиги, завершить его и убедиться, что возраст вырос на 1;
- повторно вызвать завершение того же сезона и убедиться, что повторной выплаты/старения нет;
- проверить /finishallleagues на тестовой базе и команды в Telegram.
